FrontFix AI — Proposed Multi-Agent Architecture

          

            Engineered with a 4-tier processing pipeline to guarantee deterministic accuracy, zero credential leakage, and AST-verified code modifications.
          

        


        
        

          
          

            

              1
              Ingestion & Privacy
            

            
Catches error events from browser or Vite overlay. Strips Bearer tokens, JWT headers, and PII before LLM dispatch.

          

          
          

            

              2
              Agentic Router
            

            
LangGraph routes issues to domain specialists: React Lifecycle Agent, Network CORS Agent, CSS Layout Agent, or Console Agent.

          

          
          

            

              3
              Vector RAG
            

            
Retrieves verified context chunks from ChromaDB containing MDN Web Docs, React 19 RFCs, and browser compatibility tables.

          

          
          

            

              4
              AST Diff Synthesis
            

            
Validates syntax trees, isolates the minimal failing code chunk, and outputs side-by-side unified code diffs.

          

        


        
        

          
Domain Specialist Agents:

          

            

              
1. React Component & Lifecycle Specialist

              

                Specialized in React 19 Server Components, SSR hydration boundaries, `useEffect` stale closures, and hook dependency arrays. Prevents re-render loops and memoization pitfalls.
              

            

            

              
2. Network, CORS & API Contract Specialist

              

                Specialized in Cross-Origin Resource Sharing (CORS), preflight OPTIONS requests, JWT cookie authentication, and TanStack Query / SWR network synchronization.
              

            

            

              
3. CSS Stacking & Layout Specialist

              

                Detects CSS Stacking Context traps (transform/opacity), Flexbox minimum content size overflow (`min-width: 0`), and responsive grid collapse.
              

            

            

              
4. Runtime Console & Source Map Specialist

              

                Un-minifies obfuscated production stack traces using `.map` files, isolates nullish reference exceptions, and resolves asynchronous unhandled promise rejections.
